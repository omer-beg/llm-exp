# LLM Experiments

This repo contains some experiments of running and deploying LLMs 

## Current Contents
Qwen3.5-4B-ur-colab.ipynb: This file contains a simple demonstration of text generation in Urdu using Hugging Face Transformers and the Qwen3.5-4B model.
